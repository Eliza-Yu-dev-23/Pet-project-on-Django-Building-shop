# Бесплатные сервисы проверки контрагентов

Задача — подключить к разделу «Проверка контрагента» реальный источник данных
по ИНН. Ниже — варианты, у которых есть бесплатный доступ (постоянный тариф,
демо-режим или открытые данные ФНС).

## Сравнение

| Сервис | Что даёт | Бесплатные возможности | Ограничения | API |
|---|---|---|---|---|
| **ФНС «Прозрачный бизнес»** (pb.nalog.ru) | Официальные сведения ЕГРЮЛ/ЕГРИП, задолженность, дисквалификация, массовые адреса | Полностью бесплатно | Нет публичного REST API с ключом: открытые данные (XML/JSON-выгрузки) или запросы к сайту | Неофициальный / выгрузки |
| **Открытые данные ЕГРЮЛ/ЕГРИП** (egrul.nalog.ru, nalog.gov.ru/opendata) | Полные реестры компаний и ИП | Бесплатно | Большие объёмы, нужна своя ETL-обработка, данные обновляются с задержкой | Файлы |
| **DaData.ru** | Реквизиты по ИНН, руководитель, адрес, ОКВЭД, статус, подсказки | Бесплатный тариф с суточным лимитом запросов | Лимит запросов, часть риск-аналитики — в платных тарифах | REST + API-ключ |
| **Checko.ru** | Данные ФНС, арбитраж, финансы, риски, связи | Бесплатный API для некоммерческого использования | Лимит частоты запросов, требуется указание источника | REST |
| **ЗАЧЕСТНЫЙБИЗНЕС** | Проверка рисков, связей, истории изменений | Бесплатный базовый доступ, ограниченный API | Часть отчётов платная, лимиты | REST (ограниченно) |
| **Контур.Фокус** | Глубокая аналитика: риски, связи, арбитраж, финансы | Демо-доступ / пробный период | Постоянное использование платное | REST (по договору) |
| **БФО ФНС** (bo.nalog.ru) | Бухгалтерская отчётность компаний | Бесплатно | Только финансовая отчётность, нет общих сведений о компании | REST/выгрузки |
| **РБК Компании** | Карточки компаний, финансы, суды | Бесплатный веб-доступ | Публичного бесплатного API нет | Нет |
| **СБИС / СПАРК** | Полная проверка контрагентов | Пробный доступ | Платно | По договору |

## Рекомендация

Для учебного/пет-проекта оптимальна связка:

1. **DaData.ru** — как основной быстрый источник по ИНН: простой REST API,
   бесплатный тариф, понятная авторизация по API-ключу. Даёт название,
   ОГРН, дату регистрации, руководителя, адрес, ОКВЭД и статус компании.
2. **ФНС «Прозрачный бизнес» / открытые данные ЕГРЮЛ** — как официальный
   fallback и источник налоговой задолженности.
3. **БФО ФНС** — при необходимости добавить финансовые показатели.

Контур.Фокус стоит рассматривать как ориентир по функциональности и для
демонстрации, но не как постоянный бесплатный источник — у него только
пробный/демо-доступ.

## Как подключить в проекте

Точка интеграции — `core/services/counterparty.py`, функция
`run_counterparty_check(inn, name)`. Сейчас она возвращает демо-результат
`build_demo_result`.

Пример для DaData (псевдокод):

```python
import os
import requests

def run_counterparty_check(inn: str, name: str) -> dict:
    response = requests.post(
        "https://suggestions.dadata.ru/suggestions/api/4_1/rs/findById/party",
        headers={
            "Content-Type": "application/json",
            "Accept": "application/json",
            "Authorization": f"Token {os.environ['DADATA_API_KEY']}",
        },
        json={"query": inn},
        timeout=10,
    )
    response.raise_for_status()
    item = response.json()["suggestions"][0]["data"]
    return {
        "status": "Надёжный" if item["state"]["status"] == "ACTIVE" else "Высокий риск",
        "status_class": "success" if item["state"]["status"] == "ACTIVE" else "danger",
        "risk_score": 10 if item["state"]["status"] == "ACTIVE" else 80,
        "risk_label": "низкий",
        "ogrn": item["ogrn"],
        "registration_date": item["state"]["registration_date"],
        "director": item["management"]["name"] if item.get("management") else "—",
        "legal_address": item["address"]["value"],
        "okved": item["okved"],
        "employees": 0,
        "arbitration_cases": 0,
        "tax_debts": False,
        "sanctions": False,
        "bankruptcy": False,
        "source": "dadata",
        "checked_at": timezone.now().isoformat(),
        "comment": "Данные DaData.ru",
    }
```

Ключ хранить в переменной окружения `DADATA_API_KEY` и передавать в контейнер
через `docker-compose.yml`, не коммитить в git.

## Важно про кэширование

По условию задачи проверка по интеграции выполняется не чаще раза в 30 дней
на компанию. Это снижает расход бесплатных лимитов:

* при повторной проверке в течение месяца используется сохранённый JSON
  из `HistoryCheckCounterparty.result`;
* запись в историю создаётся только при реальном вызове интеграции;
* последние 6 записей показываются всегда.
