# Проверка контрагентов: источник данных

## Какие данные выводит проверка

Название, статус и оценка риска (0–100), ОГРН/ОГРНИП, дата регистрации,
руководитель, юридический адрес, основной ОКВЭД, численность сотрудников,
число арбитражных дел, признаки налоговой задолженности, санкций и банкротства.

## Почему не Контур.Фокус

API Контур.Фокуса платный и бесплатного тарифа не имеет: минимальный пакет
«Базовые данные API» стоит от 96 000 ₽ в год, тестовый ключ выдаёт менеджер по
заявке. Сотрудники и санкции для юрлиц в нём отдельными данными не выделены.

## Выбранный сервис: Checko (api.checko.ru, v2)

| Данные проверки | Откуда берутся |
|---|---|
| Название, ОГРН/ОГРНИП, дата регистрации, руководитель, адрес, ОКВЭД, статус, численность | `/v2/company` (юрлица) или `/v2/entrepreneur` (ИП) |
| Арбитражные дела | `/v2/legal-cases` (поле `ЗапВсего`, роль «ответчик») |
| Банкротство, ликвидация | текстовый статус ЕГРЮЛ из `/v2/company` |
| Налоговая задолженность | блок `Налоги` из `/v2/company`; если в ответе нет — не показывается |
| Санкции | в API Checko отдельного метода нет; показываются только если поле `Санкции` пришло в ответе |

Бесплатный тариф: 100 запросов в сутки. Одна проверка тратит 2 запроса, то есть
до 50 проверок в сутки. Результат кэшируется на 30 дней.

Оценка риска считается локально: ликвидация (+60), банкротство (+40), санкции
(+50), налоговая задолженность (+25), арбитражные дела (+3 за дело, максимум 10),
компания младше года (+15) или трёх лет (+5). Порог: до 30 — «Надёжный»,
30–64 — «Средний риск», 65 и выше — «Высокий риск».

## Настройка

1. Зарегистрироваться на [checko.ru](https://checko.ru) и взять ключ на вкладке API.
2. Указать его в `.env`: `CHECKO_API_KEY=...` (для Docker переменная передаётся
   в контейнер через `docker-compose.yml`).

## Обработка ошибок

Любая проблема (нет ключа, сеть, таймаут, HTTP-ошибка, исчерпан лимит, пустой
или неверный ответ) приводит к тому, что пользователь видит «Произошла ошибка».
Технический текст ошибки сохраняется в колонке
`HistoryCheckCounterparty.error_text` и на сайте не показывается. Такие записи
не попадают в историю проверок на сайте, не считаются в статистике и не
используются как кэш.

Код: `core/services/counterparty.py` (функция `run_counterparty_check`).
Случайные демо-данные остались только для команды `seed_demo`
(`core/services/demo_data.py`).
