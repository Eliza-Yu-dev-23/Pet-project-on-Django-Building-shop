Бесплатные сервисы проверки контрагентов

Сейчас используется демо-заглушка. Для реальной проверки можно подключить один из бесплатных источников:

  • ФНС «Прозрачный бизнес» и открытые данные ЕГРЮЛ/ЕГРИП

    Официальные данные ФНС: регистрация, руководитель, адрес, виды деятельности, налоговая задолженность, дисквалификация. Бесплатно, без коммерческих лимитов, но API требует парсинга открытых данных или выгрузок.

    Подходит как основной источник юридически значимых сведений.

  • DaData.ru

    Бесплатный тариф с ограничением по количеству запросов в сутки. Отдаёт данные ЕГРЮЛ/ЕГРИП по ИНН, подсказки адресов и реквизиты. Простой REST API и понятная документация.

    Хороший вариант для быстрого старта: достаточно API-ключа и одного HTTP-запроса.

  • Checko.ru

    Бесплатный API для некоммерческого использования с ограничениями по частоте. Агрегирует данные ФНС, арбитраж, финансы и риски.

  • ЗАЧЕСТНЫЙБИЗНЕС

    Бесплатный базовый доступ и ограниченный API. Показывает риски, связи и историю изменений компании.

  • Контур.Фокус

    Полноценный платный сервис, но есть демо-доступ и пробный период. Подходит для оценки качества данных перед покупкой лицензии.

  • БФО ФНС (bo.nalog.ru)

    Бесплатная бухгалтерская отчётность компаний. Можно использовать как дополнительный источник финансовых показателей.
